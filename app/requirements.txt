# 3456H 彩票分析大盘

这是一个中文的 Streamlit 版彩票数据分析大盘，支持：

- 读取 CSV 历史数据
- 号码出现频率分析
- 热号 / 冷号展示
- 近期走势观察
- AI 风格建议
- 随机组合生成

## 运行方式

### 1）Docker 运行（推荐）

在仓库根目录执行：

```bash
docker compose up --build
```

浏览器打开：

```text
http://localhost:8501
```

### 2）本地 Python 运行

```bash
cd app
python -m pip install -r requirements.txt
streamlit run app.py
```

浏览器打开：

```text
http://localhost:8501
```

## 数据格式

支持以下格式示例：

```csv
date,n1,n2,n3,n4,n5,n6
2026-01-01,3,11,19,27,33,42
```

也支持类似：

```csv
date,ball1,ball2,ball3,ball4,ball5,ball6
```

## 说明

本工具仅用于历史数据统计和演示，不保证中奖。
