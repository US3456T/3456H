# 3456H 生产级 AI 彩票分析大屏

当前版本提供一个可本地运行的中文分析大屏：

- CSV 上传与输入校验
- 号码频率、热号、冷号、近期走势
- 历史特征构建：总次数、近 3/5/10/20 期、遗漏间隔
- 随机森林启发式模型
- 时间顺序切分回测，避免随机打乱造成的明显数据泄漏
- 模型分数、数据质量提示和演示组合
- Docker 与本地 Python 两种运行方法

## 运行

```powershell
docker compose up --build
```

然后打开 `http://localhost:8501`。

不使用 Docker：

```powershell
cd app
python -m pip install -r requirements.txt
streamlit run app.py
```

## CSV 格式

```csv
date,n1,n2,n3,n4,n5,n6
2026-01-01,3,11,19,27,33,42
2026-01-08,5,9,18,22,30,45
```

## 重要限制

这里的“模型分数”是历史样本上的启发式排序，不是实际中奖概率。彩票开奖结果具有随机性，模型不能保证预测成功，也不构成投注建议。请只使用合法、公开、经授权的数据，并自行保留原始数据备份。
